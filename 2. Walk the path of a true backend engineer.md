# Backend Engineering Notes 🧠

> **Backend engineering from first principles — concepts, internals, trade-offs, and production thinking.**

These notes are focused on understanding backend engineering beyond frameworks and CRUD APIs.

The objective is to understand **how backend systems work, why they are designed the way they are, how their components interact, and what trade-offs engineers make in production systems.**

# 21. Graceful Shutdown & Security 🛑🔐

## Graceful Shutdown

A server should finish existing work before terminating.

```text
Shutdown Signal
      ↓
Stop accepting requests
      ↓
Finish in-flight requests
      ↓
Close connections
      ↓
Close resources
      ↓
Terminate
```

### Signals

* SIGTERM
* SIGINT
* SIGQUIT

---

## Security

Security is a system-wide concern.

### Common Attacks

* SQL Injection
* NoSQL Injection
* XSS
* CSRF
* Broken authentication
* Insecure deserialization

### Security Principles

**Least Privilege**

Only provide the permissions required.

**Defense in Depth**

Use multiple layers of protection.

**Secure Defaults**

Default configurations should be secure.

**Separation of Duties**

Avoid unnecessary concentration of privileges.

**Security by Design**

Security should be considered from the beginning.

### Additional Topics

* Input validation
* Sanitization
* Rate limiting
* CORS
* SameSite cookies
* Content Security Policy
* Security monitoring

## Concurrency vs Parallelism

### Concurrency

Managing multiple tasks.

Useful for I/O-bound work:

* Network requests
* Database queries
* File operations

### Parallelism

Executing multiple tasks simultaneously.

Useful for CPU-bound work.

```text
Concurrency
→ Multiple tasks in progress

Parallelism
→ Multiple tasks executing simultaneously
```

# 🎯 Interview Mindset

For backend engineering interviews, knowing definitions isn't enough.

For each concept, think through:

### What?

What is it?

### Why?

What problem does it solve?

### How?

How does it work internally?

### When?

When should it be used?

### Trade-offs?

What do we gain and what do we sacrifice?

### Failure?

What happens when it fails?

### Scale?

What changes when traffic or data grows?

### Production?

How would this behave in a real system?
